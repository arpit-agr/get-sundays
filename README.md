# The problem in clear words

Given a year and month, return an array containing every date in that month that falls on a Sunday. Return each date in YYYY-MM-DD format.

## What the problem doesn’t say

The problem does not say what happens in case of any of the following:

- empty input
- wrong input type
- decimals
- months outside 1-12

In the above cases, the code throws an error.
